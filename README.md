# ☕ daOrla Café

Site institucional desenvolvido para a **daOrla Café**, com o objetivo de apresentar a cafeteria, seus produtos e proporcionar uma experiência moderna e agradável para os clientes.

## 📌 Sobre o projeto

O **daOrla Café** é um projeto de desenvolvimento web criado para representar a identidade de uma cafeteria de forma moderna, elegante e responsiva.

A proposta é criar uma presença digital que permita aos visitantes conhecer o espaço, conferir o cardápio e encontrar facilmente as principais informações sobre o estabelecimento.

## ✨ Funcionalidades

* 🏠 Página inicial com apresentação da cafeteria
* ☕ Seção de produtos e especialidades
* 📖 Cardápio
* 📍 Informações de localização
* 📱 Design responsivo para celulares, tablets e computadores
* 🎨 Interface moderna e intuitiva
* 📞 Área de contato
* 🔗 Integração com redes sociais

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura das páginas
* **CSS3** — Estilização e responsividade
* **JavaScript** — Interações e funcionalidades
* **Git/GitHub** — Versionamento e hospedagem do código

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de criar um site que combine **design, usabilidade e identidade visual**, oferecendo aos clientes da daOrla Café uma maneira simples e agradável de conhecer a cafeteria.

Além disso, o projeto faz parte do meu portfólio de desenvolvimento web, colocando em prática conceitos de **HTML, CSS, JavaScript, responsividade e organização de projetos**.

## 📱 Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela, buscando proporcionar uma boa experiência tanto em:

* 📱 Smartphones
* 📲 Tablets
* 💻 Notebooks
* 🖥️ Desktops
